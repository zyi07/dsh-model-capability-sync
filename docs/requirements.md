# 需求（已确认）

## 目标

给 DeepSeek Harness 里**已经配置好**的 LLM 供应商补全模型能力参数，让官方适配器能正确
声明上下文窗口、输出上限、输入模态（含图片）与推理档位；同时把模型列表的**名称**和
**顺序**整理到一眼能看懂。

三件事都在同一个设置页（「模型能力同步」）内完成：

1. 补全能力（写配置字段）
2. 名称重定向（写 `name` 字段）
3. 排序与重排（调整模型数组顺序）

## 非目标

- 不实现 LLM 适配器，不发推理请求，不注册 provider 路由。
- 不替代官方模型选择器，不接管对话。
- 不修改 dsh 本体。
- **不改模型 ID**：名称重定向只写 `name`，实际调用、路由、计费都不受影响。

## 功能需求

| 编号 | 需求 | 验收 |
| --- | --- | --- |
| F1 | 读取指定配置条目（默认 `llm-pi-ai`）下某供应商的模型清单 | 设置页显示模型数量与 id |
| F2 | 从 models.dev 拉取目录并缓存 | 6 小时内重复分析不再下载；可手动刷新 |
| F3 | 把网关 id 匹配到目录条目 | 展示匹配来源（精确/折叠/版本点/去变体/前缀/逐段剥前缀/名称/别名）与目标 `provider/modelId` |
| F4 | 计算能力字段：`contextWindow`、`maxTokens`、`input`、`reasoningEfforts` | 预览表逐行展示，空值显示 `—` |
| F5 | 默认只填空白字段；可勾选覆盖 | 不勾选时已有值不变 |
| F6 | 逐行勾选后写入配置 | 写入后 `cordis.patch.yml` 对应条目出现新字段，界面不重启生效 |
| F7 | 未匹配模型原样保留并单列 | 列表可见，不写入 |
| F8 | 名称降级匹配：id 各规则都落空时，用显示名称（剥掉来源标注后）再匹配一次 | `qoder/qfmodel` 这类不透明 id 也能补全能力；重命名前后解析结果一致 |
| F9 | 变体标记剥离：27 个销售点后缀、路由标签、构建号循环剥除 | `gemini-3.8-flash-tiered` → `gemini-3.8-flash`；`...-preview:free` → 去掉两者 |
| F10 | 前缀匹配：网关截断尾部时按前缀找目录条目 | `nemotron-3.5-lightning` → `nemotron-3.5-lightning-30b-a3b` |
| F11 | 逐段剥供应商前缀 | `cline/dots-studio/dots-3-note-preview:free` → `dots-studio/dots-3-note-preview` |
| F12 | 名称重定向：**自动**给所有模型加 `【供应商】` 前缀（无前缀归 `【other】`），前缀在名称**最前面** | 同名不同来源可区分；重复应用不叠加；幂等 |
| F13 | 排序二选一：按模型前缀分组 / 按重定向后【来源】名称排序 | 两种视角可切换，均为供应商优先 |
| F14 | 一键重排：按当前排序把模型数组写回配置 | 点一次即重排，不需要开关或逐行选择 |
| F15 | 补全、重定向、重排三个动作都按当前排序落盘 | 列表顺序与配置顺序始终一致 |
| F16 | 别名表：手工把网关 id 指向目录 id（P3） | 未匹配 id 可被救回 |
| F17 | 迁移旧适配器清单并停用旧插件（P4） | 模型选择器只剩官方适配器清单 |

## 匹配规则阶梯（由严到松）

1. 精确
2. 忽略大小写
3. 版本点折叠（`claude-sonnet-4.5` → `claude-sonnet-4-5`）
4. 剥变体标记（循环）
5. 前缀匹配
6. 逐段剥供应商前缀
7. 显示名称（再试其最后一段）
8. 别名（手工兜底，放最后以免被同名行继承）

同分时优先**第一方厂商**的目录条目，其次事实最全的。

## 非功能需求

- 零运行时依赖：宿主产物不 import 任何第三方包（`undici` 仅代理路径按需动态导入）。
- 宿主半不读写配置文件；写入只经官方 settings 服务。
- 中文优先的界面文案，英文同步维护。
- 类型检查与构建可离线复现（`npm install` 后 `npm run build`）。
- 单元测试离线可跑（`npm run test:rename|match|sort`），不依赖 profile 或网络。

## 明确不做

- `top_p` / `seed` / `presence_penalty` / `frequency_penalty` / `response_format`：
  dsh 的调用配置没有这些字段的来源。
- 助手侧图片输出：dsh 的 assistant 内容块没有图片类型。
- 多网关并存：本插件只处理"已配置的"供应商条目，不做网关管理。
- 重写用户自起的名称：名称重定向只剥除/追加来源前缀，不猜测、不翻译、
  不替换用户已写的模型名部分。
